Likembe lab

Same pattern engine as custom/core/likembe_core.h (checked by task host:parity). Two voices = two applet instances: Voice 1 = left hemisphere (inputs TR1, TR2), Voice 2 = right hemisphere (TR3, TR4).

Clock — internal clock (docs/CLOCK.md): Src Int = the voice's ClockSetup slot multiplier while running (one value: edited here or on the voice's Clock page Div); Src TRn = the TR jack, Div = pulses per step

Reference only (not in the firmware):
Reference layers run with the internal clock on their own 4-beat bar (16 or 12 steps), independent of the voices (Beat = every 4 steps). TR steady = 4 pulses per beat at the BPM (the ClockSetup input PPQN default), for testing Src TRn / Div.

Lab / constants — firmware constants (likembe_constants.h). Apply at the next bar line; live rows apply immediately.
